# OpenVision

An open-source AI research ecosystem focused on Computer Vision, Machine Learning, and Neural Networks.

The goal of OpenVision is to build reusable AI systems where each project contributes components, models, and knowledge to future projects.

---

# Projects

## Computer Vision

| Project | Description |
|---|---|
| [VisionCore](./VisionCore) | Shared computer vision foundation containing image processing utilities, camera interfaces, visualization tools, and common algorithms. |
| [VisionTrack](./VisionTrack) | Real-time object detection and tracking system using modern computer vision techniques. |
| [VisionPose](./VisionPose) | Human pose estimation and body tracking using deep learning models. |
| [VisionDepth](./VisionDepth) | Depth estimation and 3D perception using stereo vision and neural networks. |
| [VisionOCR](./VisionOCR) | Text detection and recognition pipeline for understanding images and documents. |
| [SceneUnderstanding](./SceneUnderstanding) | AI system for understanding objects, environments, and relationships in images. |
